# Multipage — 4 sidor + medlemsbio

Struktur (efter gruppens önskad struktur):
- index.html — INICIO: presentation (hero) + teasers
- spelningar.html — PRÓXIMAS PRESENTACIONES: kommande spelningar med banner + Köp biljetter, samt TIDIGARE spelningar (filmer från bl.a. Kungsträdgården och Gröna Lund)
- galleri.html — NOSOTROS/GALERÍA: foton från event + alla tolv musikerna; klicka på ett kort → medlem.html?n=<namn> visar bio i samma stil
- medlem.html — bio-sida (delad mekanism med hybrid-versionen via members.js)
- boka.html — CONTACTO: bokning/kontakt
- members.js, i18n.js, gigs.js, style.css — delade filer
